# 待办问题

## 2026-11-25：公开主页缺少性别或年龄时如何处理（待讨论）

问题：不少用户未在公开主页披露性别或年龄。开启对应硬性筛选后，这些候选资料不足，会留待核实，影响找人效率；资料未公开、读取失败、信息冲突也需要继续区分。

本轮决定：暂不实现新判断方案；不通过昵称、头像、自拍或主页视频猜测性别或年龄。保持现有公开字段核验和硬性筛选，未知不补造、不直接记作不符合。

后续需要共同确定：是否提供“严格核实 / 资料待确认候选”两种策略，待确认对象如何展示与人工确认；年龄不明时怎样落实年龄限制，读取失败与确实未公开分别如何处理。未获得决策前，不以推测值代替已核实信息。
