# Auto Love Finder｜全自动找对象流水线

**从零开始，让 AI 自动帮你找对象——你定标准，它来找人、筛选、开聊，帮你从线上相识，走向线下见面。**

想找对象，却还没有人选；想找游戏搭子，却不知道去哪认识；想联系同校的学长学姐，又迟迟没有开口。

现在，你可以给自己配一个专属的 **AI 社交分身**。

不用先准备人选，也不用先攒联系人列表。设定寻找目标、搜索来源和筛选条件，Agent 就能从抖音视频与评论中发现候选，筛出值得认识的人，再根据你的设置完成关注、开场和后续聊天。

**第一句话不用憋，下一句话有人接，多个聊天窗口也不用来回盯。**

它会记住聊过的话题，接住对方刚说的细节，在交流中逐步完善你的人设表达——让你的兴趣更鲜明，让你的表达更有趣，让更有魅力的你被看见。

多位联系人的交流分别处理，各自保留聊天记录和话题。你不必突然变成社交高手，也能给自己配上一整支助攻团，让更多认识彼此的机会继续往前走。

当聊天渐入佳境、彼此有了默契，AI 能顺势提出自然的邀约，在你确认安排后，让屏幕里的话题延续到一次真实的见面。

今天找对象，明天找游戏搭子，后天认识兴趣同好。想认识哪类人，你来定；重复的寻找、筛选和聊天步骤，让 AI 帮你跑起来。

**把盯屏等回复、反复想开场的时间省下来，留给真正让你心动的人。**

缘分不必只靠等。现在，让你的 AI 开始替你创造相遇。

## 第一次启动

1. 下载并完整解压源码，保留整个目录结构。
2. 双击根目录 **启动Auto Love Finder.cmd**。首次会下载 Electron 37.2.6 并校验 SHA-256；无需另外安装 Node、Python 或 Git。需要 Windows 64 位、PowerShell 和可用网络。
3. 下载失败时会显示原因，可在网络恢复后重试。以后的启动使用本目录中的运行环境缓存。

## 从空白开始配置

1. **模型**：添加自己的模型服务，填写接口地址、自己的 API Key 和服务商提供的模型 ID，保存并测试。以 DeepSeek 为例，接口地址可填 `https://api.deepseek.com/v1`；模型 ID 使用“获取模型列表”或按服务商说明填写。此版本不附送密钥或模型额度。
2. **设置 → 本人信息库**：填写自己的真实介绍，提取后审核资料和披露范围，再确认保存。空白初始状态不带开发者资料。
3. **对话 → 打开登录窗口**：登录抖音并同步联系人。自动回复默认关闭，开启后默认先生成草稿。
4. **训练场**：可先使用虚拟对象确认模型工作，再用已同意接收测试消息的账号测试真实聊天。

### 聊天模型推荐

**建议优先试用豆包 Doubao-Seed-Character**，该系列面向角色表达与自然聊天场景。当前模型 ID 示例为 `doubao-seed-character-260628`，实际可用版本或推理接入点 ID 以火山方舟控制台为准。[官方模型说明](https://docs.volcengine.com/docs/ark/model-release-announcement?lang=zh)

使用豆包时，接口地址填写 `https://ark.cn-beijing.volces.com/api/v3`，API Key 使用自己在火山方舟开通的密钥，并先开通对应模型、保存后测试。上面的 DeepSeek 地址只用于 DeepSeek 服务。[官方接口地址与鉴权说明](https://console.volcengine.com/ark/region:cn-beijing/docs/base-url-and-authentication)

同时支持其他 OpenAI 兼容模型服务，可按聊天体验、速度和实际费用选择。本项目不附送密钥或模型额度。

## 寻找和首句

- **交友发现 → 寻找设置**：填写关键词、标签或收藏夹，默认示例为“找对象，同城交友”和“脱单，找对象”。多个词可用中英文逗号、顿号、分号或换行分隔，也支持竖线与斜线；空格保留在一个词内。默认先组合搜索，并优先读取标题实际命中更多词的视频，可关闭组合搜索。
- 本批结果紧接在寻找设置下方。地区、公开性别、年龄和回复数等已启用的条件继续生效；资料未知、读取失败或冲突会分别记录，不用昵称或照片猜测。
- **所有评论 / 人工标注**：查看已采评论、纠正分类，或新建自定义目标，先“采样并标注”再寻找。批次启动时冻结目标和人工案例，暂停后修改不影响原批次继续执行。
- **全部候选**：保留跨批次的有意愿候选，方便人工筛选与调整意愿等级；手动停止也保留已采集的数据和已有候选。
- **首句生成要求**位于寻找设置中的“我的介绍”上方。选择“AI按要求生成”填写要求，或选择“直接使用固定首句”填写1～80字。固定模式不调用首句模型，个人介绍不是首句的前置条件。已有卡片点“重新生成首句”才会更新。
- “关注并发送第一句”是独立的真实操作，会在确认后尝试执行。发送结果待核实时先核对实际聊天，不要把“待核实”当作“未发送”反复重试。筛选命中本身不等于获得自动联系权限。

## AI 自动聊天

**找到人，聊下去，再让更有魅力的你被看见。**

从第一句招呼到日常来回，AI 结合你确认的个人资料、对方的消息和已有聊天记录生成回复。随着交流，逐步丰富你在对话中的兴趣表达与个性风格，记住已经向这位联系人表达过的内容，帮助后续聊天保持连贯。

你不用每次都对着聊天框想半天；让 AI 帮你整理怎么说、顺着什么聊，把更多精力留给真正的交流。

- **AI 自动完善聊天人设。** 围绕已知资料与真实交流，逐步丰富你的兴趣表达、态度和说话风格，并记住已经说过的内容。帮助你呈现更完整、更有魅力的自己，同时不改写学历、学校、家庭等核心身份事实。
- **记得前面聊到哪。** 利用已保存的对话、话题和联系人记忆，帮助延续之前的交流。
- **多位联系人，分别处理。** 每个人保留各自的记录和话题，支持多联系人自动回复。
- **连发几条，也能一起接。** 将短时间连续收到的消息合并处理，减少漏接上下文和逐条抢答。
- **图片、视频也能参与话题。** 配置具备相应能力的模型并开启媒体识别后，可结合识别到的内容生成回复。
- **想自动聊，也能先过目。** 进入 **对话** 开启自动回复；默认先生成草稿，审核后发送，也可按需切换自动发送。暂停、联系人 AI 开关和发送频率设置继续生效。

- **迈向线下，也记住重要约定。** 聊到见面等需要本人决定的事项时，会转交你确认；已记录的现实约定可在 **承诺中心** 查看、改期和标记完成。

## 主动伴聊

进入 **任务 → AI伴聊**，可填写“伴聊话题素材”，例如今天发生的一件趣事。填了就优先围绕素材生成文字开场，不额外编造经历；留空沿用自主选题。素材过时后请更新或清空。填写不会立即群发，仍遵守伴聊开关、草稿模式、频率与联系人限制。

## 数据与更新

登录态、模型配置、人设、联系人和聊天保存在当前目录的 `data/` 中；不会读取开发版或旧正式版的数据。运行环境和下载缓存分别在 `.runtime/`、`.cache/` 中。

这些目录已经配置为 Git 忽略项。测试后上传 GitHub 时仍要检查提交列表；不要使用“强制添加”上传被忽略的数据，也不要在网页中拖入使用过的整个目录。重新分发请使用本次保留的干净源码压缩包。

## 开发者测试

普通使用不需要安装开发工具。开发者安装 Node.js 22 或更高版本后，可在仓库根目录运行 `npm test`。测试使用隔离数据和模型桩，不需要真实密钥或抖音登录；输出位于被忽略的 `test-artifacts/`。

请按 [新手验收清单](docs/新手演示清单.md) 从头测试。版本、已验证范围及限制见 [版本说明](docs/版本说明.md)。
